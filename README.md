# FPS Coach AI v2

회원가입 없이 바로 사용하는 무료 MVP입니다.

## 기능
- VALORANT / OVERWATCH 2 선택
- 직접 전적 입력
- 종합 점수 / 에임 / 교전 효율 / 임팩트 / 포지셔닝
- 최근 20경기 기록
- 최근 10경기 점수 추세
- 다음 경기의 한 가지 목표
- 맞춤형 코칭 메모
- 모바일 반응형
- 회원가입/서버/API 키 없음

## 실행
압축 해제 후 `index.html`을 브라우저로 열면 됩니다.
배포할 때는 정적 호스팅에 세 파일을 올리면 됩니다.

## 데이터 저장
분석 기록은 브라우저의 `localStorage`에 저장됩니다. 따라서 계정 없이도 같은 브라우저에서 기록을 유지할 수 있습니다. 다만 브라우저/사이트 저장 데이터를 삭제하거나 다른 기기에서 접속하면 기록을 공유하지 않습니다.

## 배포
GitHub Pages, Cloudflare Pages, Netlify, Vercel 같은 정적 호스팅에 올릴 수 있습니다.

## 주의
점수와 등급은 프로젝트용 코칭 지표이며 게임의 공식 MMR/랭크를 의미하지 않습니다.
